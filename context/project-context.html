Software Developer
Portfolio Website

Een single-page React portfolio gericht op het aantrekken van stage-aanvragen én freelance opdrachten — donker, tech-achtig, en professioneel.

Doel: Stage + Freelance
Framework: React + Vite
Styling: CSS
Hosting: Vercel

02 Pagina Structuur (Single Page)
01
Hero / Introductie Eerste indruk
De eerste sectie die een bezoeker ziet. Naam, rol, en een korte tagline die beide doelgroepen aanspreekt. Twee CTA-knoppen en een subtiel typing-animatie effect.
Naam + titel Tagline: stage + freelance CTA: "Bekijk projecten" CTA: "Neem contact op" Beschikbaarheidsbadge Typing-animatie
02
Skills / Technieken Compact
Snelle visuele scan voor bezoekers. Icoontjes en namen van technologieën die je beheerst. Compact gehouden — niet te veel ruimte innemen.
React / TypeScript Node.js SQL / databases Git / GitHub CSS Custom Properties + meer
03
Ervaring Vertrouwen opbouwen
Tijdlijn van stages, schoolopdrachten en eventuele freelance klussen. Elke entry heeft een label zodat bezoekers meteen weten wat relevant is. Referentie-quotes van begeleiders of docenten.
Timeline formaat Labels: Stage / Project / Freelance Periode + bedrijf Korte beschrijving Referentie-quotes
04
Projecten Bewijs van werk
Card-grid met screenshots, beschrijvingen en technologie-tags. Elk project heeft een badge die aangeeft of het een schoolproject, freelance of persoonlijk project is. Klikbaar voor meer details in een modal of uitklapveld.
Card-grid layout Screenshot per project Tech-tags (React, Firebase…) Badge: Schoolproject / Freelance / Persoonlijk Modal met meer info GitHub-link per project
05
Contact Twee doelgroepen
Eén contactformulier dat beide doelgroepen aanspreekt. Intro-tekst: "Stage-aanvraag of freelance project? Stuur me een bericht." Aangevuld met directe links naar LinkedIn en GitHub.
Naam + email + bericht EmailJS (geen backend) LinkedIn-knop GitHub-knop Dual-purpose tekst

05 React Componenten Overzicht
<Navbar /> Sticky navigatie, smooth scroll naar secties, blur-achtergrond bij scrollen
<Hero /> Naam, tagline, typing-effect, twee CTA-knoppen, beschikbaarheidsbadge
<Skills /> Grid van technologie-icoontjes met naam, compact en visueel
<Experience /> Verticale tijdlijn met items — elke entry heeft label, periode, rol, beschrijving
<ExperienceItem /> Enkelvoudig ervaringsitem; herbruikbaar met props voor type, datum, beschrijving
<Projects /> Responsieve card-grid met filteropties per type (alle / school / freelance)
<ProjectCard /> Screenshot, naam, beschrijving, tech-tags, badge, GitHub-link, modal trigger
<ProjectModal /> Uitgebreide projectdetails: meerdere screenshots, volledige beschrijving
<References /> Quote-blokjes met naam, functie en bedrijf van referentiepersoon
<Contact /> Formulier (naam, email, bericht) via EmailJS + LinkedIn/GitHub knoppen
<Footer /> Minimaal: naam, social links, copyright

07 Volgende Stappen

Project opzetten

Vite + React installeren, CSS instellen, mappenstructuur aanmaken, Google Fonts importeren.

Global styles & variabelen

CSS variabelen voor kleuren, typografie en spacing definiëren in global.css :root {}. Reset en base styles instellen.

Hero sectie bouwen

Eerste component: Navbar + Hero. Typing-animatie toevoegen, CTA-knoppen en beschikbaarheidsbadge.

Data structureren

Projecten en ervaringen als JavaScript-objecten in data/ mappen plaatsen zodat de componenten dynamisch renderen.

Overige secties + animaties

Skills, Experience, Projects en Contact bouwen. Framer Motion scroll-reveals toevoegen voor een gepolijste feel.

EmailJS koppelen & deployen

Contactformulier verbinden met EmailJS. GitHub repo aanmaken en verbinden met Vercel voor automatische deploys.
